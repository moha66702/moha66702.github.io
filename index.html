BatiSense Pro

Type
Final-year engineering project (PFE)
Co-author
Kouachi Aissam
Outcome
Presented to a jury, entered in Startup DZ
Stack
STM32, Arduino, ESP32-CAM, Raspberry Pi, Flask, SQLite, Mosquitto, Chart.js, KiCad

A multi-node IoT system that monitors a building: kitchen gas and motion, energy use, and water. It was my PFE (final-year project), defended before a jury and entered in the Startup DZ competition. I also built the pitch deck and a five-minute presentation video.

A Raspberry Pi 3B+ gateway receives the LoRa packets and stores readings in SQLite. A Flask dashboard shows them live through server-sent events, with Chart.js graphs and a separate admin panel.

Problems I solved along the way

The parts of the project that took the most debugging, and what fixed them.

LoRa packets not decoded

Sender and receiver used different sync words. Both now use 0x34, with 433 MHz, SF7, 125 kHz and coding rate 4/5.

Unstable radio power

Supply instability on the radio module showed up during bench tests. An AMS1117-3.3 regulator was the fix to use, and I also dealt with the 5 V Arduino against 3.3 V radio logic level mismatch.

Receiver library broke on the Pi

pyLoRa did not work with Python 3.13 on Debian Trixie. Switching the GPIO layer to rpi-lgpio solved it.

Moving the dashboard to a new server

Migrating the Flask app from Railway to the school server meant fixing API base URLs, route prefixes, session cookie settings and a data directory path bug.

I also wrote the project report in French as a bilingual French and Arabic XeLaTeX document, including a market study with SWOT analysis and break-even calculations.

How BatiSense Pro was built

  1. 01

    Sense

    STM32, Arduino and ESP32-CAM nodes read gas, motion, vibration, temperature, humidity, the electricity meter and the water meter.

  2. 02

    Link

    LoRa at 433 MHz tuned on the bench until the packets decoded.

  3. 03

    Collect

    A Raspberry Pi gateway with Mosquitto, SQLite and a Flask receiver started by systemd.

  4. 04

    Show

    A Flask dashboard with live server-sent events, Chart.js graphs and an admin panel.

  5. 05

    Deploy

    Hosted on Railway, then moved to the school server.
