## Featured Project — BatiSense Pro

**BatiSense Pro** is a smart-building monitoring project developed as my final-year engineering project (PFE), in collaboration with **Kouachi Aissam**.

The system is designed to collect building data from distributed sensor nodes, transmit it to a central gateway, and make the information available through a web dashboard.

### System architecture

- **Sensor and embedded nodes:** STM32, Arduino, and ESP32-CAM platforms.
- **Wireless communication:** SX1278 LoRa modules operating at 433 MHz for long-range, low-power node-to-gateway communication.
- **Gateway:** Raspberry Pi 3 Model B+.
- **Messaging and backend:** Mosquitto MQTT broker and a Python Flask backend.
- **Data storage:** SQLite.
- **Web dashboard:** JavaScript, Chart.js, and Server-Sent Events (SSE) for live updates.

### Main monitoring capabilities

- Environmental monitoring, including temperature and humidity.
- Gas and motion-related monitoring.
- Building utility monitoring, including water, gas, and electricity consumption.
- Centralized visualization of sensor readings and system status.

**Project links:** [PFE repository](https://github.com/moha66702/batisense) · [Portfolio](https://moha66702.github.io)

> The BatiSense repository documents the web platform and system architecture. Some embedded firmware and gateway-side components are not included in that repository.
